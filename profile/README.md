# GitHard

Boot camp for your GitHub repos. GitHard is a Claude Code plugin that sets up your org and repos the way you'd want them a year from now, then helps you run them: rulesets, pinned Actions, fork PRs read before they run, and a reply for every contributor.

- **[githard](https://github.com/getgithard/githard)**: the plugin, its skills and their evals.
- **[githard-site](https://github.com/getgithard/githard-site)**: [githard.dev](https://githard.dev) and [the docs](https://docs.githard.dev).

It isn't released yet. The first release is planned before the new year.

New here? Look for issues labelled [good first issue](https://github.com/search?q=org%3Agetgithard+label%3A%22good+first+issue%22+state%3Aopen&type=issues). Each one says which files to change and what "done" looks like.
