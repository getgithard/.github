# getgithard/.github

The getgithard org's front page and default community files. `profile/README.md` is what you see at [github.com/getgithard](https://github.com/getgithard). The other files apply to every getgithard repo that doesn't have its own copy.

To change them, open a pull request here.

The files here are kept in sync by GitHard's `org-setup` skill (`bootstrap-dotgithub.sh`).
